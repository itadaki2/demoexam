ЧАСТЬ 1. СОЗДАНИЕ БАЗЫ ДАННЫХ (РЕД ЭКСПЕРТ)
На экзамене первым делом нужно подготовить базу данных (БД) и заполнить ее начальными данными.

1.1. Создание файла базы
Открой программу РЕД Эксперт (или DBeaver, что будет установлено).

Нажми кнопку «Создать базу данных» (обычно иконка с плюсом или в меню База данных -> Создать).

В поле «Путь» (или Database URL) укажи папку, которую легко найти. Например: /home/user/exam.fdb (Обязательно запомни этот путь!).

Введи стандартные данные доступа:

Пользователь: SYSDBA

Пароль: masterkey

Нажми «ОК». База появится в списке слева. Дважды кликни по ней, чтобы подключиться.

1.2. Создание таблиц и заполнение (SQL)
Нажми кнопку «SQL редактор» (иконка чистого листа с надписью SQL).

Скопируй туда этот универсальный скрипт. Он создает роли, пользователей и главную таблицу (назовем ее Items, на экзамене переименуешь в Agents, Products и т.д.):

SQL
-- 1. Создаем роли
CREATE TABLE Roles (
    Id INT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    Title VARCHAR(50) NOT NULL
);

-- 2. Создаем пользователей
CREATE TABLE Users (
    Id INT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    RoleId INT NOT NULL,
    Login VARCHAR(50) NOT NULL,
    Password VARCHAR(50) NOT NULL,
    FOREIGN KEY (RoleId) REFERENCES Roles(Id)
);

-- 3. Создаем главную таблицу (Справочник)
CREATE TABLE Items (
    Id INT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    Title VARCHAR(100) NOT NULL,
    Price DECIMAL(10,2) NOT NULL
);

-- 4. Заполняем базовыми данными для проверки
INSERT INTO Roles (Title) VALUES ('Админ'), ('Клиент');
INSERT INTO Users (RoleId, Login, Password) VALUES (1, 'admin', 'admin');
INSERT INTO Items (Title, Price) VALUES ('Тестовая запись 1', 1000);
INSERT INTO Items (Title, Price) VALUES ('Тестовая запись 2', 2000);
Выдели весь текст и нажми кнопку «Выполнить» (зеленый треугольник / Play).

САМОЕ ВАЖНОЕ: Обязательно нажми кнопку «Commit» (зеленая галочка или дискета). Без этого данные не сохранятся в файл!

Закрывай РЕД Эксперт. База готова.

ФАЙЛ 3: MainWindowViewModel.cs (В папке ViewModels)
Зачем: Это мозги главного окна. Тут поиск и загрузка данных.

C#
using System.Collections.ObjectModel;
using System.Linq;
using ReactiveUI;
using ExamProject.Entities; 

namespace ExamProject.ViewModels;

public class MainWindowViewModel : ViewModelBase
{
    private string _searchText = "";
    private ObservableCollection<Item> _items; // Если таблица называется иначе, поменяй Item на свое

    public MainWindowViewModel()
    {
        LoadData();
    }

    public string SearchText
    {
        get => _searchText;
        set 
        { 
            this.RaiseAndSetIfChanged(ref _searchText, value);
            LoadData(); // Перезагружаем список при вводе текста
        }
    }

    public ObservableCollection<Item> Items
    {
        get => _items;
        set => this.RaiseAndSetIfChanged(ref _items, value);
    }

    public void LoadData()
    {
        var query = DbHelper.Context.Items.AsQueryable();

        // Поиск по слову в колонке Title (поменяй Title на нужную колонку из БД, если надо)
        if (!string.IsNullOrWhiteSpace(SearchText))
        {
            query = query.Where(x => x.Title.ToLower().Contains(SearchText.ToLower()));
        }

        Items = new ObservableCollection<Item>(query.ToList());
    }
}

КАК ДОБАВИТЬ НОВЫЕ КОЛОНКИ В ТАБЛИЦУ
Представим ситуацию: в билете написано, что в справочнике товаров нужно вывести не только «Название» и «Цену», но еще «Описание» и «Количество на складе».

Шаг 1: Добавляем это в базу данных (SQL)
Когда будешь создавать таблицу в РЕД Эксперт (Часть 1.2 из прошлой инструкции), просто добавь эти строчки:

SQL
CREATE TABLE Items (
    Id INT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    Title VARCHAR(100) NOT NULL,
    Price DECIMAL(10,2) NOT NULL,
    -- ВОТ НОВЫЕ КОЛОНКИ:
    Description VARCHAR(255),  -- Описание (текст)
    Stock INT                  -- Количество (целое число)
);
Шаг 2: Обязательно делаем Scaffold!
Если ты изменил базу данных, твой код в VS Code ничего об этом не знает! Тебе нужно обязательно выполнить длинную команду генерации кода в терминале (команда из Части 2.3). Программа сама посмотрит в базу и увидит: "Ага, появились Description и Stock".

Шаг 3: Выводим на экран (в файл MainWindow.axaml)
Открываешь MainWindow.axaml. Находишь там блок <DataGrid.Columns>.
Чтобы добавить новую колонку, ты просто копируешь строчку <DataGridTextColumn ... /> и меняешь в ней два слова.

Было:

XML
<DataGrid.Columns>
    <DataGridTextColumn Header="Название" Binding="{Binding Title}"/>
    <DataGridTextColumn Header="Цена" Binding="{Binding Price}"/>
</DataGrid.Columns>
Стало (просто скопировал и вставил ниже):

XML
<DataGrid.Columns>
    <DataGridTextColumn Header="Название" Binding="{Binding Title}"/>
    <DataGridTextColumn Header="Цена" Binding="{Binding Price}"/>
    
    <DataGridTextColumn Header="Описание товара" Binding="{Binding Description}"/>
    <DataGridTextColumn Header="Остаток на складе" Binding="{Binding Stock}"/>
</DataGrid.Columns>
Всё! Ты добавил новые данные на экран.

🚨 СПАСАТЕЛЬНЫЕ ПОДСКАЗКИ (На случай, если что-то пойдет не так)
1. Что если текст в колонке не помещается или слишком узкий?
По умолчанию колонки сжимаются по тексту. Чтобы сделать их красивыми, добавь слово Width="*". Звездочка означает «занять всё свободное место».

XML
<DataGridTextColumn Header="Название" Binding="{Binding Title}" Width="*"/>
2. Что если в билете просят сделать галочку (Чекбокс)?
Например, в базе есть колонка IsActive (работает товар или нет). Если ты выведешь ее через TextColumn, там будет написано True/False. Чтобы была красивая галочка, используй слово CheckBox вместо Text:

XML
<DataGridCheckBoxColumn Header="Активен?" Binding="{Binding IsActive}"/>
3. Ошибка: Красное подчеркивание в XAML и проект не запускается.

Причина: Ты где-то не закрыл кавычки "" или забыл поставить слеш / в конце тега (например, <TextBox ... > вместо <TextBox ... />). XAML очень строг к этому.

Решение: Внимательно посмотри на красную волнистую линию, обычно забыта мелочь вроде /> в конце строки.

4. Ошибка: Данные в таблице пустые, хотя в базе они есть!

Причина: Опечатка в слове Binding="{Binding ...}".

Решение: Если в базе колонка называется Title, а ты написал Binding="{Binding title}" (с маленькой буквы) — ничего не выведется! C# строго различает большие и маленькие буквы. Пиши точь-в-точь как в базе данных (база данных обычно делает всё с большой буквы).

5. Ошибка при выполнении Scaffold-DbContext (красный текст в терминале)

Причина: Чаще всего ты ошибся в пароле masterkey, логине SYSDBA или пути к файлу БД.

Решение: Проверь путь. В Linux (РЕД ОС) пути пишутся через прямые слеши /, например /home/user/exam.fdb. И убедись, что ты нажал Commit (сохранить) в РЕД Эксперт перед тем, как делать Scaffold.
